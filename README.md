# CORRIDOR RUSH

Музыкальный 3D-раннер от первого лица. Полёт начинается с 12 м/с, ускоряется на насыщенных фрагментах трека и замедляется до 10 м/с к последнему звуку. Игрок выбирает высоту и управляет форсажем. Станция автоматически проводит камеру через повороты на 90°.

## Запуск

[Играть в браузере на GitHub Pages](https://sergey-develop.github.io/rush/). На сайте звучит Gone With The Wind. При обновлении ветки `main` GitHub Actions запускает тесты, собирает игру и публикует каталог `dist`.

В Windows дважды нажмите **Play.cmd**. Для запуска нужны Node.js 22 и современный браузер с WebGL 2. При первом запуске скрипт загрузит зависимости, если их ещё нет.

В терминале откройте каталог проекта и выполните команды.

```sh
npm ci
npm run dev
```

Откройте локальный адрес, который напечатает Vite. Звук включается при запуске забега. Для статической сборки выполните `npm run build`, для её просмотра — `npm run preview`. Содержимое `dist` также можно раздавать с обычного HTTP-сервера.

## Управление

При открытии игры проявляются две малиновые полосы. Поверх них собирается надпись CORRIDOR RUSH и влетает аппарат. Подсказка **HEADPHONES RECOMMENDED** и шкала загрузки уступают место кнопкам меню, когда готовы иллюстрация и сцена станции. Этот же плакат приглушается за окнами рейтинга и настроек. Кнопка «Пропустить», Enter, пробел или Esc сокращают вступление. После забега меню возвращается сразу. Игра учитывает системную настройку уменьшения движения.

| Действие | Управление |
| --- | --- |
| Подняться или опуститься | Для подъёма удерживайте W или ↑, для снижения — S или ↓. При отпускании корабль сохраняет высоту. |
| Форсаж | Удерживайте Shift. Форсаж также можно включить левой кнопкой мыши. Ручной форсаж разгоняет корабль до 30 м/с. Вместе с подобранной турбиной он даёт до 38 м/с. |
| Изменить высоту на сенсорном экране | Наклон телефона включён по умолчанию. Для управления касанием коснитесь экрана на нужной высоте. |
| Повернуть в коридоре | Камера поворачивает автоматически. Стрелки на стенах и в HUD показывают направление. |
| Пауза, продолжение | Esc или экранные кнопки. При уходе с вкладки забег приостанавливается. |

Перед каждым стартом, включая повторный забег, открываются правила. Кнопка «Играть» в окне правил запускает отсчёт. Галочка «Больше не показывать» сохраняется на устройстве. Снять её можно через «Как играть» в главном меню. Во время полёта курсор скрыт и появляется снова при открытии паузы или результата.

В настройках строка «Управление» переключает клавиатуру и мышь. Выбор сохраняется на этом устройстве. Также доступны громкость, выключение звука, чувствительность управления высотой, инверсия вертикального управления, качество графики и имя пилота. Рейтинг хранит лучшие результаты на этом устройстве за неделю и за всё время. До первой записи таблица явно помечена «ДЕМО».

Три коротких щелчка отмечают отсчёт 3–2–1. На старте звучит более низкий удар и начинается музыка. Внизу полётного экрана видна голубая дуга с насечками. Во время форсажа HUD показывает скорость. При столкновении камера отскакивает от барьера, а музыка резко прокручивается назад и замедляется. Счёт и дистанция плавно проявляются целыми числами и подстраиваются под ширину рамки. При включённом уменьшении движения результат виден сразу. За прохождение всей записи открывается экран «Трек пройден» с её названием.

## Своя песня

В главном меню откройте **Своя песня → Выбрать файл** и выберите аудиозапись на устройстве. После подготовки название файла появится в окне выбора. Вернитесь в меню и начните полёт. Свет, темп трассы и момент финиша рассчитываются по выбранной записи.

Браузер обрабатывает файл локально. Песня доступна для повторных полётов до перезагрузки страницы. Чтобы сменить её, снова откройте **Своя песня**. Кнопка **Вернуть встроенную песню** восстановит исходный трек.

## Трасса и ритм

Локальная версия использует предоставленную запись **Gone With The Wind**. Базовая сетка трассы — **122 BPM**. При обычном разгоне первый проём приходится на третью долю, первый автоматический поворот — на шестую. Удержание Shift ускоряет прохождение тех же препятствий. Оригинальная запись воспроизводится в своём темпе и задаёт длительность полёта. При отсутствии записи используется 16-тактовая композиция **Phase Line** при 172 BPM.

Перед стартом игра измеряет громкость и плотность атак на протяжении музыкальных фраз. По этой карте она вычисляет базовую скорость и размещает препятствия. На последних секундах записи скорость плавно снижается. Удержание Shift прибавляет до 36,4% к базовой скорости. Турбина даёт ещё одну такую же прибавку на четыре секунды. Щит с голубым полем поглощает одно столкновение и при этом обнуляет комбо. Камера немного отходит назад, угол обзора расширяется, а вдоль стен появляются воздушные штрихи. При включённом уменьшении движения сохраняются физическое ускорение и цветовая индикация модуля. При обычной скорости каждый метр приносит 2 очка. Форсаж увеличивает награду за дистанцию. Отдельно начисляются очки за препятствия и комбо.

При первом запуске трека фоновый обработчик измеряет спектральные атаки в четырёх диапазонах декодированной записи с шагом 5 мс. Карта освещения учитывает момент и силу каждой выделенной атаки. Низкий удар зажигает янтарные лампы, шумовая атака — настенные маяки, высокий щелчок — холодные потолочные ячейки. На протяжный тон откликаются плафоны вдоль палубы. В паузах лампы успевают погаснуть.

Окантовка поля откликается на сильные акценты. Если браузер предоставляет время фактического вывода звука, вспышки учитывают задержку аудиоустройства. Громкость регулируется после анализатора. На паузе останавливаются и музыка, и свет.

В этой установке `src/assets/music/station.local.mp3` — жёсткая ссылка на исходный MP3 в корне RUSH. Параметры записи лежат в `src/assets/music/station.local.json`. Для переносимой версии без локальной записи и карты предусмотрен оригинальный синтезированный 16-тактовый брейкбит с басом, ударными, пэдами и арпеджио. Чтобы заменить встроенный трек при сборке, положите аудиофайл в `src/assets/music` и укажите его имя в карте. Поддерживаются MP3, OGG, WAV, M4A и FLAC при наличии декодера в браузере.

```json
{
  "title": "Station",
  "file": "station.ogg",
  "bpm": 160,
  "events": [
    { "beat": 4, "kind": "center" },
    { "beat": 8, "kind": "right" },
    { "beat": 12, "kind": "top" }
  ]
}
```

`beat` отсчитывается от нулевой доли. Допустимые события — `top`, `center`, `bottom`, `left`, `right`. Оставляйте не менее 1,3 с до первого события и между соседними событиями. После боковой секции следующий угол возвращает трассу к продольному направлению. Это правило сохраняет непересекающиеся полосы пространства. Когда список заканчивается, трасса продолжается по фиксированному seed.

Необязательный параметр `offsetSeconds` задаёт позицию начала воспроизведения в пользовательском файле. Финиш определяется длительностью декодированной записи вплоть до её последнего сэмпла. При наличии нескольких карт приоритет имеет первая по имени карта с указанным `file`.

## Архитектура станции

Вдоль трассы чередуются семь отсеков: технический, трубопроводный, вентиляционный, электротехнический, наблюдательный, аварийный и усиленный. Левая и правая стены собираются по разным схемам. В настиле проложен обслуживаемый канал с решётками и съёмными крышками. На потолке видны разрезные кассеты, двутавры, воздуховоды и подвесы для жгутов. В поворотах оборудование отступает от лётного габарита.

Панели, окрашенные рамы, трубы и пороги используют карты цвета, нормалей, шероховатости и металличности. Сколы у креплений открывают сталь. Маркировка SECTOR 03 нанесена на глухую панель соседнего отсека. В широком иллюминаторе видны ближняя рама, поверхность Луны и дальние звёзды. При движении они смещаются по-разному.

Для поверхности Луны использованы мозаика LROC и карта высот LOLA миссии Lunar Reconnaissance Orbiter. Обе карты хранятся в `src/assets/moon`. Карта высот в игре охватывает диапазон от −10 до +12 км. Материалы подготовлены NASA’s Scientific Visualization Studio и Эрни Райтом. [NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/)

Дымка движется вдоль отсека и плотнее у пола и под потолком. Рассеянный свет рассчитывается от тёплых фонарей, холодных ламп и барьера до ближайшей видимой поверхности. На низком качестве используются меньше отсчётов вдоль луча и более низкое разрешение объёмного эффекта.

## Проверки и контрольные кадры

```sh
npm test
npm run build
npm run test:browser
npm run test:browser -- --screenshots ./visual-check
```

Браузерный тест запускает временный локальный сервер и отдельный профиль Chrome или Edge. Путь к другому Chromium можно задать переменной `CHROME_PATH`. Он проверяет игровой цикл через обычные кнопки и ввод, затем закрывает браузер и сервер.

В режиме разработки доступны две сцены для ручного визуального сравнения.

- `/?view=reference` при 1245 × 686, DPR 1. Это размер области главного меню на иллюстрации новой станции. Фиксируются фаза освещения, камера меню и центральный барьер. Координаты камеры в метрах равны x = 0,47, y = −0,58 и z = −3,30. Вертикальный FOV равен 64°, плоскость барьера проходит через z = −13 м.
- `/tests/reference.html` при 1272 × 704, DPR 1. Это контрольный кадр игровой камеры на оси коридора при FOV 69°, ровно за 9,8 м до первого поля. Кадр используют те же генератор, симуляция, материалы и HUD, что и обычный забег.

Горизонтальная и вертикальная иллюстрации меню и аппарат хранятся отдельными слоями в `src/assets/interface`. В 3D-коридоре фактура металла, электрические разряды и отражение силового поля на полу рассчитываются процедурно. Сложность забега — **Normal**.

### Результаты проверки

- Модульные тесты охватывают разгон и форсаж, очки, коллизии, генерацию, автоматические повороты, изменение ритмического рисунка, тишину и обратную прокрутку. Двухчасовая симуляция проверяет границы данных активной трассы.
- В Chrome проверены удержание и отпускание ЛКМ, независимое управление высотой, отдача камеры, плавное появление статистики, естественный конец записи, повторный запуск и сохранение рекорда.
- В двух полётах до одного и того же барьера на дистанции 60,36 м обычный полёт дал 520 очков, а удержание ЛКМ — 633.
- В Chrome полностью пройдена исходная запись длительностью 318,72 с. При коротком использовании форсажа пройдено 218 событий и 6 976 м, финишная статистика показала 198 482 очка.
